# ctrl Plater integration

This is temporary.

## Installation

- Open Plater, click the mods tab, create new.
- Add the following documents, and paste in the contents from the files in this directory:
    - CONSTRUCTOR
    - INITIALIZATION
    - NAMEPLATE_UPDATED

## Notes

- Textures are in /assets/plater
- Fonts are in /assets/fonts
- Mob database is in /DB.lua
